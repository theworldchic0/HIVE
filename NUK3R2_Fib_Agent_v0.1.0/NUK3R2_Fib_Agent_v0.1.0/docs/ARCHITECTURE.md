# Hive Integration

Research Agent -> Watchlist -> Fib Agent -> reaction history -> Master List.

Sub-agents:
1. Market Data Worker
2. Anchor Worker
3. Fib Calculator
4. Young Token Worker
5. Volume Confirmation Worker
6. Reaction Tracker
7. Fib Learning Worker
8. Data Integrity Worker

Inputs:
- Research: token, contract, chain, archetype, narrative, watchlist status
- Market Direction: macro/regime context
- Bottom Blueprint: bottom-window context
- Narrative Agent: stage/curve/context

Outputs:
- Fib structures
- anchor evidence
- reaction events
- integrity flags
- learning observations
- re-check events

Master List is the lifetime research record. Append timestamped observations; do not overwrite history.

Queen Bee audits data quality, source reliability, usage, errors, duplicate work and learning sample size. It can recommend changes but cannot activate them without beekeeper approval.
