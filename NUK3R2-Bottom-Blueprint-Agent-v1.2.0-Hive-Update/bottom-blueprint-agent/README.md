# NUK3R2 Bottom Blueprint Observatory v1.2.0

Independent durable agent for the Bottom Blueprint.

Its main purpose is **experimental measurement**: keep the Blueprint visible, record its predictions exactly as published, monitor the live window, receive research cohorts, and measure how those cohorts perform from their original research timestamps through the bull-cycle end or fifth-halving boundary.

It is not a replacement Blueprint and not a trading agent. The original snapshots are immutable.

The UI should keep this agent visible on the main Hive overview as a compact banner/card because its job is both contextual and experimental.
